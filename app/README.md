# NeuroScan Web Application

This folder contains the web application interface and backend components for the NeuroScan brain MRI classification project.

## Components

- `app.py` — Flask application backend.
- `server.py` — Alternative Python server implementation.
- `index.html` — Web application interface.
- `style.css` — Application styling.
- `script.js` — Frontend interactions and prediction requests.
- `neuroscan_engine.py` — Model-related prediction logic.
- `export_model.py` — Model export and evaluation artifact generation.
- `neuroscan_evaluation.froc` — Evaluation data artifact.

## Running the Application

Setup instructions and the application startup command will be finalised after the backend and model files have been tested.

## Disclaimer

This is an academic project and is not a medical diagnostic tool. Predictions must not be used to make medical or treatment decisions.
